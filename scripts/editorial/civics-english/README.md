# 公民與英文逐題編寫紀錄

已完成：115 年，公民 1–35 題、英文 36–50 題。其餘年度不以樣板或答案字母自動填入。

- `115.txt` 每行為題號、帶讀摘要、A/B/C/D 個別理由、查證來源代碼，以 `|` 分隔；`~` 為段落分隔。
- 反向題在題號後加 `!`，只用於產生清楚的「敘述正誤／是否應選」標籤；實質理由均逐題撰寫。
- `115-vocabulary.json` 保存英文單字、詞性、字義及語境。46–50 題閱讀共用一份詞表，避免單獨開啟某題就看不到題組單字。
- 執行 `python scripts/editorial/civics-english/build.py` 產生 `data/explanations/115-1.json`；再執行正式建置即可複製至公開資料並更新覆蓋數。
- 法規題依題意保留當年官方計分。第 9 題「無助於」、第 16 題韓國解任建議及第 27 題二讀議決的表述界線有特別註記；不擅改答案、不為排除選項而編造理由。
- 來源以全國法規資料庫、司法院、立法院、法務部、韓國法制處及原卷／標準答案為主。新增內容查核日期為 2026-10-19。
- 英文未來壽命閱讀的數字與數位生命主張均以「依本文」解讀，不將文章預測當成已證實的醫學結論。
