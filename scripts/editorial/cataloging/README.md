# 中文圖書分類編目大意逐題解析

九個年度各 50 題，共 450 題；每題四個選項，共 1,800 則選項理由。

`106.txt` 至 `115.txt` 為逐題撰寫的編輯原稿，每行依序為題號、讀題與答案說明、A 至 D 的理由、查證來源代碼。題號後 `!` 表示題目問錯誤敘述；`~` 表示段落分隔。`build.py` 只轉換檔案結構，不依官方答案拼造解釋。

修改原稿後執行 `python scripts/editorial/cataloging/build.py`，再建置網站。新題或修訂仍需人工檢查內容，涵蓋率與字數測試不能代替事實審核。

參考國圖編目園地的 CCR 第三版、中文分類法 2007 年版及實務問答，並參考 LC、IFLA、W3C、OCLC、Getty 等機構的相關標準。各題保留可點選的延伸來源。

已特別註記 FAST 歷史與現行層面數、SKOS 可新建概念綱要、FRBR 評論與表現形式的區別、URI/URL 與單件條碼的用詞疑義。歷年服務範圍、機關名稱與規則版本以該題年代理解，不以舊題推斷今日所有現況。

`question-corrections.json` 記錄對照原卷後修復的 106 年第 15、18、35 題圈碼選項。原卷不納入專案，題目與答案字母保持官方內容；108 年第 36 題依官方更正接受 A/B/C/D，解析不把一律給分等同於四種規範功能完全相同。
