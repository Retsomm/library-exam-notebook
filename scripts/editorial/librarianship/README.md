# 圖書館學大意逐題解析

九個年度450題、1,800則逐選項理由。TXT每行依序為題號、兩段白話解析、A至D理由、來源代碼，以半形直線分隔。題號尾端驚嘆號表示反向題，波浪符號表示分段。

`sources.tsv` 保存來源代碼、顯示標題及官方或原始資料URL。`build.py` 嚴格檢查七欄、來源存在、每年50題，生成 `data/explanations/{year}-2.json`；它不依答案自動生成內容。正式建置讀取已檢入的JSON。

爭議題另有明確判斷覆寫：例如114年第48題網站工程、107年第38題資訊近用與隱私、106年第43題像素與影像品質。保留官方計分，不為迎合答案捏造理由。106年第2、4、21題圈碼還原依據記錄於 `question-corrections.json`。

驗證：`npm test`、`npm run build`、`node tests/http-check.mjs`。靜態HTTP檢查核對三科共1,305題已提供解析，且PDF、ZIP不在網站上。
