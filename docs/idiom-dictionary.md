# 國文成語庫

唯一詞卡來源為 `data/idioms.json`。現有 106–111、113–115 年共 405 道國文題，整理 589 筆成語、熟語、典故與題辭，對應 249 題、674 個詞卡－原題關聯。收錄範圍包含題幹、各選項及閱讀文章；不是宣稱國語中所有成語都在題庫內。

詞目先以教育部《成語典》公開詞目及《重編國語辭典修訂本》詞目索引比對，再補查成語用法題、引號內詞語及題辭。詞目索引僅用於找候選詞；釋義及例句另行編寫，沒有匯入辭典釋義、書證或例句全文。排除書名、人名、機關名與科技術語等非本區範圍的詞。原卷的錯誤用法不能直接拿來當正確例句。

- `term` 為主詞形；`aliases` 保存異寫與對照詞形。相同詞跨年只有一張卡，近義但不同的成語仍分開講解。
- `meaning` 包含白話意思及必要的用法辨析；`example` 是完整原創示範句。
- `questionIds` 必須列出詞形在國文題幹、選項或文章內出現的全部題目，按題庫順序。不要將兩個選項接起來搜尋，避免誤配。
- `reviewedQuestionIds` 記錄本次已掃描題目。新增年度時應補查新詞、寫好詞卡，再更新這份清單，不能只自動蓋上已檢查標記。
- `lib/idioms.mjs` 共用文字正規化、來源比對及搜尋。更新詞卡後執行 `npm test`，來源漏列、錯列、重複主詞形會失敗。
- 顯示由 `IdiomCard` 統一負責；原題列與原有主題卡共用 `StudyQuestionSource`，官方連結共用 `OfficialSourceLink`。練習與解析仍交回 `StudyApp` 的既有流程。
- 搜尋可查詞形、意思、例句與完整題號；年度篩選顯示該年度的原題出處，頁面大小為 20。
